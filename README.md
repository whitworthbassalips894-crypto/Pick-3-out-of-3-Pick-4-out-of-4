# 六合彩「7码复式 · 三中三 / 四中四」每日选号工具（简洁一页版）

纯静态 HTML / CSS / ES Module 的 PWA 单页工具，免构建，可托管于 GitHub Pages 或任意静态服务器，支持离线访问。

> 本版按「一页流」重构：取消原来的 4 个 Tab 模块与双模式切换，打开页面自上而下就是完整流程；核心算法与 2022–2026 共 1,757 期历史底库保持不变。
>
> 界面按 `222.html` 的浅色风格重做（背景 `#f6f8fb`、白卡片、金色强调），并补齐「加载中…」死循环的修复、版本化缓存与历史逐期回放。

## 页面结构（一页五段）

1. **今日推荐** — 默认展示下一期的 S1 综合主推 7 码 + 精选 5 注三中三 / 5 注四中四，一键复制整期方案；选往期自动显示开奖复盘（命中正码数、复式与精选的注数及净收益）。S1～S5 五组策略收在折叠区，点「用作主推」即可替换。
2. **自选 7 码** — 唯一的 49 码选号盘：点选、设胆码（点已选球）、按策略智能补齐；输入 6 个正码即可试算命中；35 注全展开收在折叠区。
3. **开奖核对** — 一行输入「6 正码 + 特码」即时核对主推、精选与自选，可保存到浏览器本地并与底库合并（期号 / 年份 / 日期都有非法值拦截）。
4. **历史回放** — 默认逐期回放：每期推荐只用该期之前的数据（无未来函数），列出推荐 7 码、实际 6 正码、特码、命中正码、k、三中三 / 四中四结论与中奖组合；上方有年份 / 范围 / 策略 / 投注方式 / 命中状态 / 关键词筛选，配套指标卡（成本、返奖、净盈亏、ROI）与超几何随机基线；可切「全部 1,757 期」批量回测。
5. **更多** — 本金/赔率设置、版本与缓存维护、数据同步、粘贴/文件导入全部折叠，平时不用打开。

## 规则与算法（与旧版一致）

- **命中判定**：仅核对前 6 个正码（平一～平六），特码不计入三中三 / 四中四，也不计入命中正码。
- **命中注数**：7 码复式命中 $k$ 个正码时，三中三中 $\binom{k}{3}$ 注、四中四中 $\binom{k}{4}$ 注。
- **默认参数**：单注本金 10 元、三中三赔率 650 倍、四中四赔率 7500 倍（在「更多」中可改）。
- **5 组策略**：S1 综合量化主推（默认）、S2 热温动量、S3 遗漏回补、S4 同尾连码共振、S5 生肖波色动量；回测严格无未来函数（每期只用此前数据）。
- **随机基线**：49 选 7、开出 6 个正码的超几何分布 $P(k\ge3)\approx3.10\%$、$P(k\ge4)\approx0.22\%$（见 `src/statistics.js`），只作为参照，不代表任何「必中」结论。
- **数据底库**：2022–2026 共 1,757 期，随仓库 `data/draws.json` / `data/draws.js` 发布；GitHub Actions（`workflows/sync-draws.yml`）每日抓取 `https://2026kj.zkclhb.com:2025/am.html` 自动同步，前端也支持粘贴/文件导入兜底。

## 加载失败与版本管理（重点）

- **统一构建号**：`src/constants.js` 的 `APP_BUILD`（当前 `2026.10.24-r3`）是唯一版本源；`index.html` 的 `?v=` 资源参数、`sw.js` 的 `BUILD_ID` 与缓存名都由它派生，测试 `tests/build-version.test.mjs` 会强制三处一致。
- **Service Worker**：外壳资源走「网络优先」（`cache: no-store` + `Cache-Control: no-cache` + `?sw=<BUILD>`），失败才回退缓存；数据文件走缓存优先；激活时按版本清理旧缓存，并 `skipWaiting` + `clients.claim()`。
- **不会再永远「加载中…」**：`index.html` 内联了一个启动看门狗（不依赖任何外部脚本），脚本加载失败或初始化中断时直接显示错误面板，并提供「重新加载 / 修复缓存并重载 / 彻底重置（注销 SW）」三个入口。
- **升级不丢数据**：`src/storage.js` 负责读写与旧键名迁移，本金赔率、自选号码、胆码、本地录入的开奖在升级、修复缓存后依然保留。

## 目录结构

```text
├── index.html              # 一页流主界面（五段）+ 内联启动看门狗
├── assets/
│   ├── styles.css          # 浅色主题样式（222.html 风格）
│   └── icon.svg            # 应用图标
├── src/
│   ├── constants.js        # 波色、生肖、默认配置、构建版本号
│   ├── combinatorics.js    # 组合展开与命中/收益核算、命中分类
│   ├── strategy.js         # S1~S5 推荐引擎、逐期回放与批量回测
│   ├── parser.js           # HTML / 文本 / JSON 解析与幂等合并
│   ├── statistics.js       # 超几何随机基线（P(k≥3)、P(k≥4)）
│   ├── storage.js          # localStorage 读写、旧键名迁移、脏数据清洗
│   └── app.js              # 前端交互主控制器（一页流）
├── data/draws.json|js      # 2022–2026 历史开奖底库 (1757 期)
├── scripts/                # 底库重建与远程同步脚本
├── workflows/sync-draws.yml# GitHub Actions 每日同步
├── manifest.webmanifest    # PWA 清单
├── sw.js                   # Service Worker（版本化缓存 + 网络优先）
└── tests/                  # 组合/解析/策略/底库/统计/回放/存储/版本测试
```

## 常用命令

```bash
npm test      # 运行单元测试与底库完整性校验（40 个用例）
npm start     # 本地静态预览（http://localhost:3000）
npm run sync  # 从远程源同步最新开奖到 data/
```
