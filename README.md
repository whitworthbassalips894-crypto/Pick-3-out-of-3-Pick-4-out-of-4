# 六合彩「7码复式 · 三中三 / 四中四」每日选号网页工具（PWA 单页版）

纯静态原生 HTML / CSS / ES Module 构建的六合彩「7码复式 · 三中三 / 四中四」每日智选、命中核算与历史回放 PWA 单页工具。免构建步骤，可直接托管于 GitHub Pages 或任意静态服务器，支持离线访问。

---

## 核心特性

1. **双模式推荐与组合计算（三中三 & 四中四）**
   - **7码复式全展开 + 精选5注直选**：每期生成核心「7码复式」（自动拆解 $C(7,3)=35$ 注三中三与 $C(7,4)=35$ 注四中四全组合），并从中按历史共现协同度优选出 **5注三中三** 与 **5注四中四** 直选组合。
   - **5组策略方案对比（S1～S5）**：
     - `S1 · 综合量化主推`（热温冷均衡 + 黄金遗漏回补 + 共现对子协同 + 波色区间配比）
     - `S2 · 热温动量策略`（近15～30期高频正码动量追踪）
     - `S3 · 遗漏回补策略`（极值遗漏回归 + 邻码共振）
     - `S4 · 同尾连码共振`（强势尾数族群与连码成组优化）
     - `S5 · 生肖波色动量`（旺肖密度与红蓝绿三波均衡）
   - **49码交互选号盘 & 胆码锁定**：支持手动点选 7 码、设置 1～6 个「胆码」后按任一策略智能补齐 7 码，支持输入模拟正码实时计算 35 注命中明细与收益。

2. **严格正码核对与自定义赔率/本金**
   - **判定规则**：严格遵循传统连码标准，**仅核对前 6 个正码（平一～平六）**，特码仅作展示，绝不计入三中三/四中四命中。
   - **命中数学关系**（设 7 码复式命中 $k$ 个正码，$0 \le k \le 6$）：
     - 三中三命中组数 = $\binom{k}{3}$（中3正码=1注，中4正码=4注，中5正码=10注，中6正码=20注）
     - 四中四命中组数 = $\binom{k}{4}$（中4正码=1注，中5正码=5注，中6正码=15注）
   - **本金与赔率可调**：默认单注本金 `10 元`、三中三赔率 `650 倍`、四中四赔率 `7500 倍`，顶部配置条随时修改并实时重算当期及历史回测净收益。

3. **干净的四大核心模块**
   - **🎯 每日7码选号**：期号切换、双模式推荐卡片、5大策略对比、49码选号盘及 35 注展开。
   - **✍️ 录入开奖**：49球点选键盘 + 单行文本极速解析，录入瞬间实时核对本期三中三/四中四命中与收益。
   - **📜 历史回放（含三中三命中明细）**：支持按年份（2022–2026）、期数、策略或自定义7码回测，展开查看每期命中的具体三中三/四中四组合与账单明细。
   - **🔄 数据同步**：内置 **2022–2026 共 1,757 期完整历史开奖底库**，支持 GitHub Actions 每日定时抓取 `https://2026kj.zkclhb.com:2025/am.html` 及前端网页源码/纯文本粘贴导入兜底。

## 目录结构

```text
├── index.html                      # PWA 单页主界面（4大核心模块）
├── manifest.webmanifest            # PWA 应用配置清单
├── sw.js                           # Service Worker 离线缓存脚本
├── assets/
│   ├── styles.css                  # 响应式界面样式
│   └── icon.svg                    # 应用图标
├── src/
│   ├── constants.js                # 49码波色、生肖动态推算、默认赔率配置
│   ├── combinatorics.js            # C(n,k) 组合展开、6正码命中核对与收益统计纯函数
│   ├── strategy.js                 # S1~S5 多策略推荐引擎与无未来函数历史回测引擎
│   ├── parser.js                   # HTML源码 / 网页复制文本 / 单行简写 / JSON 通用解析与幂等合并
│   └── app.js                      # 前端交互主控制器
├── data/
│   ├── draws.json                  # 2022–2026 完整历史开奖底库 JSON (1757期)
│   └── draws.js                    # 同步生成的 ES Module 底库
├── scripts/
│   ├── build_history_db.mjs        # 从历史 HTML 重建底库脚本
│   └── sync_latest.mjs             # 抓取 https://2026kj.zkclhb.com:2025/am.html 增量同步脚本
├── .github/workflows/
│   └── sync-draws.yml              # GitHub Actions 每日定时抓取与自动提交工作流
└── tests/
    ├── combinatorics.test.mjs      # 组合数学与6正码命中收益测试
    ├── parser.test.mjs             # 多格式解析与幂等合并测试
    ├── strategy.test.mjs           # 推荐引擎、胆码锁定与历史回测测试
    └── database.test.mjs           # 2022-2026 (1757期) 底库完整性测试
```

## 常用命令

```bash
# 运行完整单元测试与底库完整性校验
npm test

# 从远程源 https://2026kj.zkclhb.com:2025/am.html 同步最新开奖记录
npm run sync

# 使用本地保存的 HTML 文件离线同步入库
node scripts/sync_latest.mjs --input /path/to/2026.html

# 启动本地静态预览服务
npm start
```
