# 六合彩 · 每日 5 注（特码 / 三中三 / 四中四）

纯前端单页工具（PWA）：每天给出 **5 注**号码，三种玩法共用一个引擎，**1 注完全随机 + 4 注风格精选**，
5 注号码**互不重叠**。附历史逐期回放、公平赔率对照、数据同步。

> 先把话说清楚：**每期开奖相互独立，没有任何选号方法能提高命中概率。**
> 本工具能做的只有两件事：① 如实算出概率与期望回报；② 把 5 注做成互不重叠，让「至少中 1 注」的概率达到上限。
> 彩票是娱乐，请量力而行。

## 三种玩法的概率（工具里也是这几组数）

| 玩法 | 每注号码 | 单注命中概率 | 理论公平赔率 | 默认赔率 → 期望回报率 |
| --- | --- | --- | --- | --- |
| 特码 | 5 个号 | 5/49 ≈ **10.2041%** | 9.8 倍 | 9.6 倍 → **98.0%** |
| 三中三 | 3 个号 | C(6,3)/C(49,3) ≈ **0.1086%** | ≈ 921 倍 | 650 倍 → **70.6%** |
| 四中四 | 4 个号 | C(6,4)/C(49,4) ≈ **0.00708%** | ≈ 14125 倍 | 7500 倍 → **53.0%** |

命中口径：
- **特码**：开奖的最后一个号码（特码）落在这注的 5 个号里就算中，6 个正码不参与判定。
- **三中三 / 四中四**：这注的 3 / 4 个号**全部**落在 6 个正码里才算中，特码不计入。

赔率与本金可以在页面「本金与赔率」里改，回放金额会同步重算。

## 5 注怎么分工

| 注 | 名称 | 选号逻辑 |
| --- | --- | --- |
| #1 | 🎲 完全随机 | 在 4 注精选没用到的号里等概率机选（可重摇，作对照组） |
| #2 | 🔥 热号 | 近 30 期出现次数最多 + EMA 活跃度 + 上期重号 / 斜邻 |
| #3 | 🎯 冷号 | 按该号自身间距分布的遗漏分位，取遗漏最久的号 |
| #4 | ⚖️ 形态均衡 | 号码靠近中值 25（和值接近理论均值），奇偶 / 大小 / 三区均衡 |
| #5 | 🧩 补位覆盖 | 补齐前 4 注没覆盖到的尾数与区段，让 5 注铺满 01–49 |

**硬约束：5 注共 5 × size 个号码互不重复**（特码 25 个 / 三中三 15 个 / 四中四 20 个）。
这是整套方案里唯一真正影响概率的部分——号码内容无关概率，覆盖才能让「5 注至少中 1 注」达到上限：

- 特码：25 个不同号 → **25/49 ≈ 51.02%**
- 三中三：5 注互不重叠 → ≈ 5 × 0.1086% ≈ **0.543%**
- 四中四：5 注互不重叠 → ≈ 5 × 0.00708% ≈ **0.0354%**

风格注（热 / 冷 / 形态 / 补位）只决定「看起来怎么选」，不改变任何一注的命中概率。

## 页面

一页流，只保留必要区块：

1. **今日 5 注** —— 玩法切换（特码 / 三中三 / 四中四）、期数切换、5 注卡片、一键复制、重摇随机注；底部一行显示单注命中率 / 公平赔率 / 期望回报率 / 5 注至少中 1 注。
2. **历史回放** —— 逐期用「该期之前的数据」重算 5 注并核对命中，给出逐注命中次数与 ROI、随机基线对照（无未来函数）。
3. **数据** —— 折叠：读取仓库 `data/draws.json` 同步缺失期、粘贴文本兜底、导入 / 导出本机开奖、底库体检。
4. **设置** —— 折叠：本金与赔率、版本与缓存维护。

已下线：自选号码、6 码试算、手动录入开奖、共识号、连空分布图、年份 / 命中 / 搜索等筛选控件。

## 运行

```bash
npm start          # 本地静态服务（默认 3000 端口）
npm test           # 单元测试 + 页面冒烟测试
npm run sync       # 从远程源同步最新开奖到 data/draws.json
npm run build:db   # 由 data/draws.json 生成 data/draws.js
```

页面冒烟测试用 jsdom 真跑一遍 `index.html + src/app.js`；没有装 jsdom 时会自动跳过（`npm i --no-save jsdom` 可启用）。
