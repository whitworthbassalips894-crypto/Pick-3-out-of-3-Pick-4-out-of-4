# 六合彩「特码 / 直选 · 三中三 / 四中四」每日选号工具（简洁一页版）

纯静态 HTML / CSS / ES Module 的 PWA 单页工具，免构建，可托管于 GitHub Pages 或任意静态服务器，支持离线访问。

> 本版按「一页流」重构：取消原来的 4 个 Tab 模块与双模式切换，打开页面自上而下就是完整流程；核心算法与 2022–2026 共 1,759 期历史底库保持不变。
>
> 界面按 `222.html` 的浅色风格重做（背景 `#f6f8fb`、白卡片、金色强调），并补齐「加载中…」死循环的修复、版本化缓存与历史逐期回放。
>
> **选号模型为「每日 5 注」**（`2026.10.26-r9`）：顶部一键切换 **特码（每注 5 个号）/ 选三 · 三中三（每注 3 个号）/ 选四 · 四中四（每注 4 个号）**，**默认进入特码**，5 注都是单注注单，**不再有 7 码复式 / 35 注组合 / 胆码**。
>
> **本轮更新（`2026.10.26-r9`）**：**特码玩法改为「5 注统一杀上期特码」**——上期特码在下一期继续当特码的概率只有约 1/49，因此 5 注全部把它从候选池里剔除：#1 随机注在剩下 48 个号里照旧机选（仍是纯随机对照，只是不含上期特码，重摇也一样），#2~#5 四注精选用原来的特码历史打分，但候选里没有这个号。同时把 4 注精选的「跨注安排」定成硬规则：同一个号**最多只进 2 注精选**（保留共识号，但不让 4 注全压在同一个号上）、每注**三区最多 2 个号**（5 码注收敛成 2-2-1 / 2-1-2）、**奇偶贴 3:2 或 2:3**。实测 400 期：5 注合计覆盖的不同号码从 16.4 个提高到 18.9 个，命中率仍在随机噪声范围内（每注约 10%，与 5/49 持平）。

## 页面结构（一页六段）

1. **今日推荐 · 每日 5 注** — 顶部「特码 / 选三 / 选四」切换（默认特码），固定输出 5 注：#1 🎲 随机基线（纯随机对照，可「重摇第 1 注随机号码 / 恢复默认随机」）、#2 🔥 热势恒强 / 特码热势、#3 🎯 遗漏回补 / 特码遗漏回补、#4 🔗 关联共振 / 特码尾数共振、#5 ⚖️ 三区波色均衡 / 特码三区均衡；每注给出 **5 个号（特码）或 3 个号（选三）或 4 个号（选四）** 与形态（奇偶 / 大小 / 三区 / 和值），右侧给出命中标签（已开奖时）；卡片底部是**多策略共识号**（被 ≥2 注精选同时选中的号码）。
2. **自选号码** — 49 码选号盘：点选即选（特码最多 5 个号、选三 3 个、选四 4 个），可按 5 注方案之一「智能补齐」，可「载入自选」，可输入 6 个正码（特码玩法再加 1 个特码）试算命中；选满即成 1 注。
3. **开奖核对** — 一行输入「6 正码 + 特码」即时核对 5 注与自选，可保存到浏览器本地并与底库合并（期号 / 年份 / 日期都有非法值拦截，含 `2026-13-45` 这类不存在的日期）。
4. **历史回放** — 逐期回放：每期推荐只用该期之前的数据（无未来函数）。表格列出 期号/日期 · 当期 6 正码 · 特码 · **5 注逐注命中** · 本期中奖 · 详情（展开可看每注命中号码与返奖）；上方有年份 / 范围 / 方案（每日 5 注 or 当前自选号码）/ 命中状态 / 关键词筛选；配套指标卡与**逐注对比表**（场均命中、命中期数、累计返奖、ROI）与直选随机基线；可切「全部 1,759 期」批量回测。
5. **数据同步（常驻，不折叠）** — 见下文「数据同步」。
6. **更多** — 本金/赔率设置、版本与缓存维护（全部折叠，平时不用打开）。

## 规则与算法

- **三种玩法的命中口径**（顶部切换，默认特码）：
  - **特码（每注 5 个号）**：命中 = 开奖的**最后一个号码（特码）**落在这 5 个号里，6 个正码只作展示、不参与判定；单注命中概率 $P=5/49\approx10.204\%$。
  - **三中三（每注 3 个号）/ 四中四（每注 4 个号）**：这 3 / 4 个号码**全部**落在 6 个正码里才算命中，特码不计入。
  - 三种玩法命中 1 注都返奖 = 本金 × 赔率，不中奖则亏掉该注本金。
- **默认参数**：单注本金 10 元、**特码赔率 9.6 倍**、三中三赔率 650 倍、四中四赔率 7500 倍（在「更多」中可改）。
- **特码赔率为什么是 9.6 倍**：本页一注覆盖 5 个号，命中概率 $P=5/49\approx10.204\%$，**公平赔率是 9.8 倍**。默认取 **9.6 倍**，期望回报率 $9.6\times5/49\approx98.0\%$（接近公平，仍略低于 1）。⚠ 早期版本默认写的 48 倍是「押 1 个号」的赔率，套到 5 个号上会算出 **489.8%** 的期望回报率——数学上不可能长期成立（真实博彩有抽水）；该默认值已改正，升级时会把旧配置里的 48 自动迁移成 9.6（用户自己填的其它数值不动），「更多」里仍保留 48 倍快捷值并如实标注其不现实。
- **每日 5 注**（`src/dailyfive.js`，严格无未来函数、同一期同一盐值完全可复现）：

  | 注 | 名称 | 选码依据 |
  | --- | --- | --- |
  | #1 | 🎲 随机基线 | 按目标期号定种（mulberry32 + Fisher–Yates）的纯随机对照，可重摇（特码玩法在除上期特码外的 48 个号里机选） |
  | #2 | 🔥 热势恒强 | EMA 短中周期活跃热码 + 上期重号 + 斜连邻号动量 |
  | #3 | 🎯 遗漏回补 | 个人历史遗漏 80%–98% 饱和度临界区 + 高活性热码短休回补窗 |
  | #4 | 🔗 关联共振 | 近 180 期条件转移升幅 + 同尾与两连号高频共现协同 |
  | #5 | ⚖️ 三区波色均衡 | 贝叶斯平滑频率 + 三区/波色/奇偶均衡配额 + 等隔韵律，适度跨注去重 |

  特码玩法下 4 注精选的选码依据换成**特码自己的历史**（作为特码出现的频率与遗漏、尾数族群、三区/波色/奇偶均衡配额），名称相应改为「特码热势 / 特码遗漏回补 / 特码尾数共振 / 特码三区均衡」。
  共识号 = 4 注精选中被 ≥2 注同时选中的号码（选三约 75% 的期次有共识，选四约 93%）。
- **杀上期特码（仅特码玩法）**：上期特码下一期继续当特码的历史概率约 1/49（≈2.04%），属于典型的低价值号，因此 5 注统一排除它——随机注在剩下 48 个号里机选，4 注精选直接把该号从候选池剔除（`plan.killedNumbers` / 每注的 `killed` 字段会带出来，页面头盔标签与说明里都会显示「已杀上期特码 xx」）。正码玩法的命中对象是 6 个正码，不做杀号。
- **4 注精选怎么排**：四注保留各自权重（热势 / 遗漏回补 / 尾数共振 / 三区均衡），并叠加三条结构规则——
  1. **跨注重复上限**：同一个号最多进 2 注精选（第 3 注开始该号退出候选池），既留住了共识号，又避免 4 注全压同一个号；
  2. **三区上限**：每注每个区最多 2 个号（5 码注自然收敛成 2-2-1 / 2-1-2 / 1-2-2）；
  3. **奇偶与波色**：奇偶向 2:3 / 3:2 靠拢（偏离越远扣分越多），波色不集中在单一颜色。
  实测最近 400 期：4 注精选里同一个号最多出现 2 次（旧版最多 4 次），5 注合计覆盖的不同号码从 16.4 个升到 18.9 个；各注命中率仍在随机噪声范围内（每注约 10%，与 5/49 = 10.2% 持平），没有任何一注被包装成「有优势」。
- **随机基线**（`src/statistics.js`，页面与回放区都会显示）：
  - 特码：$P=5/49\approx10.204\%$，公平赔率约 **9.8 倍**，默认 9.6 倍对应**期望回报率约 98.0%**（仍略低于 1）；若填 48 倍则高达 489.8%，页面会显式警告；
  - 三中三：$P=\binom{6}{3}/\binom{49}{3}=20/18424\approx0.1086\%$，公平赔率约 921 倍，当前 650 倍对应**期望回报率约 70.6%**（长期为负）；
  - 四中四：$P=\binom{6}{4}/\binom{49}{4}=15/211876\approx0.0071\%$，公平赔率约 14125 倍，当前 7500 倍对应**期望回报率约 53.1%**（长期为负）；
  - 场均命中号码期望 $E[k]=3\times6/49\approx0.367$（选三）/ $4\times6/49\approx0.490$（选四）码/期；特码玩法每注命中概率 $5/49\approx10.20\%$，每日 5 注至少中 1 注约 41.6%。
- **诚实表述**：5 注只在**权重**上有差异，全部落在随机噪声范围内；回放表格与指标卡都会同时显示随机期望与期望回报率，不把任何一注包装成「有优势」，不美化亏损。
- **数据底库**：2022–2026 共 1,759 期（最新 `2026-298`，2026-10-25），随仓库 `data/draws.json` / `data/draws.js` 发布；GitHub Actions（`workflows/sync-draws.yml`）每日抓取 `https://2026kj.zkclhb.com:2025/am.html` 自动同步，前端也支持粘贴/文件导入兜底。
- **复制格式**：所有复制动作输出**纯号码、每注一行、顿号分隔**（`src/copy.js`）：
  - 「📋 一键复制今日 5 注」→ 5 行，特码每行 5 个号、选三 3 个、选四 4 个，例如 `05、06、07` / `22、27、49、06、25`；
  - 「复制本注」→ 1 行（3 或 4 个号）；
  - 「复制自选」→ 1 行；
  - 共识号、注号、日期、赔率等**一律不进入剪贴板**（只有页面上的提示文字才会说明复制了什么）。

## 数据同步（常驻区块）

参考 <https://whitworthbassalips894-crypto.github.io/lottery-tool/> 的第 4 节实现，但**不折叠**，直接放在页面底部固定位置：

- **状态卡**：本地最后一期 · 数据源最新一期 · 数据源更新时间 · 本次可追加期数 · 冲突 / 缺口。
- **三个动作**：
  - 「👁 仅检查（不写入）」——只比对，不动任何数据；
  - 「🔄 一键同步」——把**连续缺失**的期号追加写入本机 `localStorage`（内置底库永不被改写）；
  - 「🛠 以数据源为准修复冲突」——同一期号号码不一致时，用数据源的版本覆盖本机记录。
- **数据源**：仓库 `data/draws.json`（带 `_r=` 参数直连网络，绕过 Service Worker 的数据缓存，保证读到的是服务器上的最新版本）；仓库数据源没有更新时，「一键同步」会再尝试一次**远程开奖源**（官网地址 + 两个 CORS 代理，浏览器跨域拦截时会明确提示改用粘贴兜底）。
- **追加规则**（`src/sync.js`，纯函数、有单元测试）：从「本地最后一期」的下一期起逐期推进，**遇到期号缺口立即停止**并报告缺口，绝不写入不连续的期号；同一期号内容不同即判为冲突，绝不静默覆盖。
- **粘贴导入兜底**：支持官网 HTML 源码、网页复制文本、手工行（`298期 2026-10-25 31 36 40 34 37 43 + 08`）、JSON / CSV；先「解析预览」看清解析了几期、可追加几期，再「解析并追加缺失期」。
- **本机开奖管理**：导出 / 导入 / 清空本机 `localStorage` 里的手动开奖记录（换设备、备份用）。

## 加载失败与版本管理（重点）

- **统一构建号**：`src/constants.js` 的 `APP_BUILD`（当前 `2026.10.26-r8`）是唯一版本源；`index.html` 的 `?v=` 资源参数、`sw.js` 的 `BUILD_ID` 与缓存名都由它派生，测试 `tests/build-version.test.mjs` 会强制三处一致。
- **Service Worker**：外壳资源走「网络优先」（`cache: no-store` + `Cache-Control: no-cache` + `?sw=<BUILD>`），失败才回退缓存；数据文件走缓存优先；激活时**只按本工具缓存前缀** `mark6-pick3-pick4-*` 清理旧缓存（不会误删同域其它工具的缓存），并 `skipWaiting` + `clients.claim()`。
- **不会再永远「加载中…」**：`index.html` 内联了一个启动看门狗（不依赖任何外部脚本），脚本加载失败或初始化中断时直接显示错误面板，并提供「重新加载 / 修复缓存并重载 / 彻底重置（注销 SW）」三个入口。
- **升级不丢数据**：`src/storage.js` 负责读写与旧键名迁移，本金赔率（含新增的特码赔率）、玩法（特码/选三/选四）、自选号码、本地录入的开奖、随机注盐值在升级、修复缓存后依然保留；旧键迁移只认带 `pick3/pk3` 标识的键，不会把同域其它工具的数据当成本工具的赔率。旧版的 `targetSize: 3 / 4` 会自动迁移成 `playMode: pick3 / pick4`，旧版本遗留的 7 码复式自选号码在进入页面时按当前玩法收敛为 5 / 3 / 4 个号（其余号码不再参与计算）。
