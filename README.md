# 六合彩「7码复式 · 三中三 / 四中四」每日选号工具（简洁一页版）

纯静态 HTML / CSS / ES Module 的 PWA 单页工具，免构建，可托管于 GitHub Pages 或任意静态服务器，支持离线访问。

> 本版按「一页流」重构：取消原来的 4 个 Tab 模块与双模式切换，打开页面自上而下就是完整流程；核心算法与 2022–2026 共 1,757 期历史底库保持不变。
>
> 界面按 `222.html` 的浅色风格重做（背景 `#f6f8fb`、白卡片、金色强调），并补齐「加载中…」死循环的修复、版本化缓存与历史逐期回放。
>
> **选号模型已改为「每日 5 注」**：1 注纯随机基线 + 4 注精选（详见下文），不再有 S1～S5 策略切换器。

## 页面结构（一页五段）

1. **今日推荐 · 每日 5 注** — 固定输出 5 注：#1 🎲 随机基线（纯随机对照，可「重摇随机注 / 恢复默认随机」）、#2 🔥 热势恒强、#3 🎯 遗漏回补、#4 🔗 关联共振、#5 ⚖️ 三区波色均衡；每注给出 7 码 + 精选 5 注三中三 / 5 注四中四、形态（奇偶 / 大小 / 三区 / 波色 / 和值）；上方给出**共识号**（被 ≥2 注精选同时选中的号码）。选往期自动显示开奖复盘（命中正码数、三中三 / 四中四注数与中奖组合、本期净收益）。
2. **自选 7 码** — 唯一的 49 码选号盘：点选、设胆码（点已选球）、按 5 注方案之一「智能补齐」；输入 6 个正码即可试算命中；35 注全展开收在折叠区。
3. **开奖核对** — 一行输入「6 正码 + 特码」即时核对 5 注与自选，可保存到浏览器本地并与底库合并（期号 / 年份 / 日期都有非法值拦截，含 `2026-13-45` 这类不存在的日期）。
4. **历史回放** — 逐期回放：每期推荐只用该期之前的数据（无未来函数）。表格列出 期号/日期 · 当期 6 正码 · 特码 · **5 注逐注命中** · 三中三 · 四中四 · 详情（展开可看每注 5+5 的逐注命中与返奖）；上方有年份 / 范围 / 方案（每日 5 注 or 当前自选 7 码）/ 投注方式（7 码复式 or 精选 5 注）/ 命中状态 / 关键词筛选；配套指标卡与**逐注对比表**（场均命中、三中三 / 四中四命中期数、累计返奖、ROI）与超几何随机基线；可切「全部 1,757 期」批量回测。
5. **更多** — 本金/赔率设置、版本与缓存维护、数据同步、粘贴/文件导入全部折叠，平时不用打开。

## 规则与算法

- **命中判定**：仅核对前 6 个正码（平一～平六），特码不计入三中三 / 四中四，也不计入命中正码。
- **命中注数**：7 码复式命中 $k$ 个正码时，三中三中 $\binom{k}{3}$ 注、四中四中 $\binom{k}{4}$ 注。
- **默认参数**：单注本金 10 元、三中三赔率 650 倍、四中四赔率 7500 倍（在「更多」中可改）。
- **每日 5 注**（`src/dailyfive.js`，严格无未来函数、同一期同一盐值完全可复现）：

  | 注 | 名称 | 选码依据 |
  | --- | --- | --- |
  | #1 | 🎲 随机基线 | 按目标期号定种（mulberry32 + Fisher–Yates）的纯随机对照，可重摇 |
  | #2 | 🔥 热势恒强 | EMA 短中周期活跃热码 + 上期重号 + 斜连邻号动量 |
  | #3 | 🎯 遗漏回补 | 个人历史遗漏 80%–98% 饱和度临界区 + 高活性热码短休回补窗 |
  | #4 | 🔗 关联共振 | 近 180 期条件转移升幅 + 同尾与两连号高频共现协同 |
  | #5 | ⚖️ 三区波色均衡 | 贝叶斯平滑频率 + 三区/波色/奇偶均衡配额 + 等隔韵律，适度跨注去重 |

  共识号 = 4 注精选中被 ≥2 注同时选中的号码。
- **随机基线**：49 选 7、开出 6 个正码的超几何分布 $P(k\ge3)\approx3.10\%$、$P(k\ge4)\approx0.22\%$、场均命中期望 $E[k]=42/49\approx0.857$ 码/期（见 `src/statistics.js`）。
- **诚实表述**：5 注只在**权重**上有差异，全部落在随机噪声范围内；回测表格与指标卡都会同时显示随机期望，不把任何一注包装成「有优势」。
- **数据底库**：2022–2026 共 1,757 期，随仓库 `data/draws.json` / `data/draws.js` 发布；GitHub Actions（`workflows/sync-draws.yml`）每日抓取 `https://2026kj.zkclhb.com:2025/am.html` 自动同步，前端也支持粘贴/文件导入兜底。

## 加载失败与版本管理（重点）

- **统一构建号**：`src/constants.js` 的 `APP_BUILD`（当前 `2026.10.25-r4`）是唯一版本源；`index.html` 的 `?v=` 资源参数、`sw.js` 的 `BUILD_ID` 与缓存名都由它派生，测试 `tests/build-version.test.mjs` 会强制三处一致。
- **Service Worker**：外壳资源走「网络优先」（`cache: no-store` + `Cache-Control: no-cache` + `?sw=<BUILD>`），失败才回退缓存；数据文件走缓存优先；激活时**只按本工具缓存前缀** `mark6-pick3-pick4-*` 清理旧缓存（不会误删同域其它工具的缓存），并 `skipWaiting` + `clients.claim()`。
- **不会再永远「加载中…」**：`index.html` 内联了一个启动看门狗（不依赖任何外部脚本），脚本加载失败或初始化中断时直接显示错误面板，并提供「重新加载 / 修复缓存并重载 / 彻底重置（注销 SW）」三个入口。
- **升级不丢数据**：`src/storage.js` 负责读写与旧键名迁移，本金赔率、自选号码、胆码、本地录入的开奖、随机注盐值在升级、修复缓存后依然保留；旧键迁移只认带 `pick3/pk3` 标识的键，不会把同域其它工具的数据当成本工具的赔率。

## 目录结构

```text
├── index.html              # 一页流主界面（五段）+ 内联启动看门狗
├── assets/
│   ├── styles.css          # 浅色主题样式（222.html 风格）
│   └── icon.svg            # 应用图标
├── src/
│   ├── constants.js        # 波色、生肖、默认配置、构建版本号
│   ├── combinatorics.js    # 组合展开与命中/收益核算、命中分类
│   ├── dailyfive.js        # 每日 5 注引擎（1 随机 + 4 精选）、共识号、逐期回放与汇总
│   ├── strategy.js         # 与策略无关的公共件（历史取样、7 码均衡挑选、5+5 组合优选）
│   ├── parser.js           # HTML / 文本 / JSON 解析、日期校验与幂等合并
│   ├── statistics.js       # 超几何随机基线（P(k≥3)、P(k≥4)、E[k]）
│   ├── storage.js          # localStorage 读写、旧键名迁移、脏数据清洗
│   └── app.js              # 前端交互主控制器（一页流）
├── data/draws.json|js      # 2022–2026 历史开奖底库 (1757 期)
├── scripts/                # 底库重建与远程同步脚本
├── workflows/sync-draws.yml# GitHub Actions 每日同步
├── manifest.webmanifest    # PWA 清单
├── sw.js                   # Service Worker（版本化缓存 + 网络优先）
└── tests/                  # 组合/解析/5注引擎/底库/统计/回放/存储/版本测试
```
